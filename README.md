## Research code

**[The Interface Contract](https://github.com/AtharvaAiren/interface-contract-artifact)** explores continual representation drift, feature repair and compatibility across model updates. The repository includes a manuscript, experiment entry points, aggregate reports and numerical checks.

[Read the repository's manuscript](https://github.com/AtharvaAiren/interface-contract-artifact/blob/main/paper/paper_with_appendix.pdf) · [Explore the evidence map](https://github.com/AtharvaAiren/interface-contract-artifact#evidence-map) · [Reproduction guide](https://github.com/AtharvaAiren/interface-contract-artifact/blob/main/docs/reproducibility.md)
